# andreaselben.github.io

Source for [andreaselben.github.io](https://andreaselben.github.io), the
personal website of Andreas Elben (Paul Scherrer Institute). The site is built
with [Jekyll](https://jekyllrb.com/) and published via GitHub Pages from the
`master` branch.

It is based on the [academicpages](https://github.com/academicpages/academicpages.github.io)
template, originally a fork of [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes)
by Michael Rose.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

The site is then available at <http://localhost:4000>.
